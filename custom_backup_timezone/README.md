# Custom Backup Timezone Module

## الوصف
هذا الموديول يخصص اسم ملف الباك أب ليستخدم المنطقة الزمنية للمستخدم بدلاً من التوقيت العالمي (UTC).

## المميزات
- استخدام المنطقة الزمنية للمستخدم في اسم ملف الباك أب
- الحفاظ على وظيفة الباك أب الأصلية
- سهل التثبيت والاستخدام
- دعم جميع المناطق الزمنية المعروفة

## التثبيت

### 1. انسخ الموديول
```
D:\Odoo_Work_Space\Pycharm_Work_Space\My_Addons\My_Addons-15\custom_backup_timezone
```

### 2. قم بتثبيت الموديول في Odoo
1. اذهب إلى قائمة التطبيقات
2. قم بإزالة فلتر "التطبيقات"
3. ابحث عن "Custom Backup Timezone"
4. قم بتثبيت الموديول

### 3. إعداد المنطقة الزمنية
يمكنك تحديد المنطقة الزمنية بإحدى الطرق التالية:

#### الطريقة الأولى: من خلال إعدادات النظام
1. اذهب إلى الإعدادات -> عام -> المنطقة الزمنية
2. اختر منطقتك الزمنية (مثال: Africa/Cairo, Asia/Riyadh)

#### الطريقة الثانية: من خلال ملف الإعدادات
أضف السطر التالي في ملف `odoo.conf`:
```
timezone = Africa/Cairo
```

#### الطريقة الثالثة: من خلال إعدادات المستخدم
1. اذهب إلى تفضيلات المستخدم
2. قم بتعيين منطقتك الزمنية

## كيف يعمل الموديول

الموديول يستخدم الوراثة (Inheritance) لتجاوز دالة الباك أب الأصلية:

1. **الوراثة من Database Controller** - يرث من `odoo.addons.web.controllers.main.Database`
2. **تجاوز دالة backup()** - يعيد تعريف دالة الباك أب مع الحفاظ على الوظائف الأصلية
3. **تحديد المنطقة الزمنية** - يقرأ من إعدادات النظام أو المستخدم
4. **تحويل التوقيت** - يحول UTC إلى التوقيت المحلي
5. **إنشاء اسم الملف** - يستخدم التوقيت المحلي في اسم الملف

### المميزات التقنية:
- استخدام `super()` للوصول إلى دوال الأب
- الحفاظ على الكود الأصلي وقابليته للصيانة
- التعامل مع الأخطاء بشكل احترافي

## مثال على أسماء الملفات

**قبل الموديول (UTC):**
```
mydatabase_2025-05-01_02-30-00.zip
```

**بعد الموديول (بتوقيت مصر):**
```
mydatabase_2025-05-01_04-30-00.zip
```

## المناطق الزمنية المدعومة
يدعم الموديول جميع المناطق الزمنية المدعومة في pytz، مثل:
- Africa/Cairo
- Africa/Algiers
- Africa/Tunis
- Asia/Riyadh
- Asia/Dubai
- Europe/London
- America/New_York
- وغيرها الكثير

## استكشاف الأخطاء

### مشكلة: لا يزال يستخدم التوقيت العالمي
**الحل:** تأكد من إعداد المنطقة الزمنية بشكل صحيح في إعدادات Odoo.

### مشكلة: خطأ في المنطقة الزمنية
**الحل:** تحقق من أن اسم المنطقة الزمنية صحيح (استخدم الأسماء المعتمدة من pytz).
